# 模型伙伴头像主题 · 2026-11-07

入口：编辑 Bot → 头像与外观 → 头像主题 → 模型伙伴。

主题由现有 `appearance.mascot` 推导，旧角色配置直接生效，不增加存储字段、接口、组件或依赖。首次切入主题选中 ChatGPT；同次编辑切回该主题会恢复上次选择的角色。切回自定义保留原部件和颜色，恢复默认头像回到原自定义主题。
