# 会话导航与群聊布局验收（2026-11-03）

## 实现

- 原 SessionSidebar 增加实时头像栏／右侧历史两种呈现；独立开发场景保持旧默认，不修改 slot registry。
- Bot 图标下放群聊组合缩略入口。顶部 Bot／群名打开同一个 OutputFrame 的「会话」来源；五个来源切换不另开平行面板，浏览器不可用时显示禁用状态。
- 右侧单聊资料为头像及实际 Harness／Model；群聊为重叠成员头像、名字与原成员菜单。成员模型按各 Bot 的 Provider 覆盖或 CLI 配置来源显示，无统一群模型。
- 范围选择与搜索同行，支持当前 Bot、群聊及全部对话的原全文搜索、分页、结果定位与历史管理。右侧各页签共用大头像资料区，产物范围与搜索也同行。
- 输入框的方框铅笔新开对话，回形针菜单容纳上传与原引用对话；删除顶部新建／邀请加号、输入框工作区按钮。邀请其他 Bot 在右侧头像菜单，创建 Bot 保留品牌入口。
- 左侧 Bot 恢复本页上次访问的会话，无历史才新建；正文阅读位置按对话保留。旧草稿、记录及后台任务不因新对话删除或停止。群聊中新对话保留当前成员和主持 Bot。
- 手机沿用左抽屉和原 Output 全屏模式；选择历史后回到聊天，Escape 关闭并恢复焦点。

## 后续修正：682px 内嵌预览无法打开右侧（2026-11-03）

用户报告后在原 682×925px 标签页复现：遮罩可见，面板实际 x≈712px、宽度为 0。导航共用样式错误地用 relative／100% 高覆盖了原展开面板的 fixed／inset。原 390px 与宽桌面检查不足以覆盖中间区间；此前“已验证”不代表该区间可用。

修复只把停靠定位规则限定到 `data-expanded="false"`，共用 flex 布局保留；没有改运行时、授权或模型。沿原 `outputKeyboard.browser.test.ts` 增加导航上下文的 390/660/682/860/1280px 检查：面板边界必须在视口内、有可用宽度，群聊历史可点击，重开后 Escape 返回触发按钮。修复前确实失败，修复后含原 HTML／表单键盘场景共 10 项通过；构建及 diff 检查通过。此次未重复完整套件。

实际用户原窗口复查右侧固定定位、宽约 572px，可打开群聊列表、选中项目讨论并查看群成员；截图 `panel-fixed-682.png`。已刷新用户正在看的构建预览，保留打开后的群聊面板。

## 后续修正：左侧群聊直接跳转与欢迎页身份栏（2026-11-04）

新增单击后的活动会话、标题、窄屏无右侧遮挡和无历史成员选择断言；修复前单击跳转断言失败，修复后导航／重连 13 项通过。原群重连测试补上真实用户消息，使它代表实际聊天而非空欢迎页；后续标题刷新断言仍保留。最终构建通过。本轮未重跑完整测试或真实模型任务。

原 Output 键盘与面板边界 10 项也已复跑通过。一次执行遇到机器长时间暂停导致父测试超时取消，原超时和断言不变重新执行通过；最终两组专项合计 23 项通过。
