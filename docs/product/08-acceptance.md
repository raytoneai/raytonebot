# 08 验收清单

每条写明怎么验。结果记到 [03-roadmap.md](03-roadmap.md) 进度日志，写“通过 / 失败 + 输出摘要 / 未验证”。不能用演示事件代替真实行为。

## 自动检查（不调用模型）

| 命令 | 覆盖 |
| --- | --- |
| `npm run build` | TypeScript + 生产构建 |
| `npm test`（`node --test src/pi/*.test.ts`） | piHost 接口、CLI 输出翻译、权限、会话存储等；piAdapter 映射快照待补 |
| `npm run check:local`（先启动服务） | Pi SDK 加载、工具注册、空 prompt 400、跨站拒绝 |
| `node scripts/cloud-preview.mjs --check` | 密码、Host/Origin、CSRF、内部标准化 |

## A 组：核心闭环（真实模型，本机先、云端后）

| # | 操作 | 期望 |
| --- | --- | --- |
| A1 | 发“只读检查工作目录有哪些文件” | 流式文本；出现 `ls`/`find` 工具卡片并完成；无审批 |
| A2 | 要求创建一个 Markdown 文件（`request` 模式） | 出现审批卡片；批准后文件写入工作区；产物/工具结果可见 |
| A3 | 同 A2 但拒绝 | 文件未写入；Agent 收到拒绝并继续说明 |
| A4 | 长任务中点停止；另注入一次停止接口失败后重试 | 成功确认后流结束、状态为已中断；接口失败时保留运行状态与停止按钮，可再次停止 |
| A5 | 新建会话后再发任务 | 新会话无旧上下文；同一 Agent 的「始终允许」仍有效（设置里可重置），其他 Agent 不继承 |
| A6 | 切换模型/思考级别后发任务 | 使用所选模型；错误配置时出现可读错误 |
| A7 | 模型 key 无效 | 显示错误事件，而不是空白或无限转圈 |
| A8 | 三个会话运行时向已有空闲会话提交；或经 HTTP 向已有运行的会话重复提交 | 被拒绝的消息与原因可见；原任务和历史不受影响 |

## B 组：持久化（M1 起）

| # | 操作 | 期望 |
| --- | --- | --- |
| B1 | 完成 A2 后刷新页面 | 侧栏会话列表与历史消息、工具卡片恢复 |
| B2 | 重启服务进程后打开 | 同 B1 |
| B3 | 恢复的会话里继续提问 | Agent 记得之前的上下文 |
| B4 | 任务执行中重启进程（M3），包含等待首个 token 的时刻 | 该轮显示为已中断；没有被自动重新执行；再次重启不重复补终态 |
| B5 | 任务中刷新并延迟历史响应、打开对话，再断开重接流；另覆盖读历史后任务恰好结束 | 任务继续；历史不覆盖新事件；断线后继续重接；任务已结束时最终内容和终态不丢失、不重复，不重放 prompt |
| B6 | 丢弃一次提交，再恢复网络读取旧会话；另在运行中持续模拟主机不可达并点停止 | 未接收的提交保留消息并报错、不自动重发；连续 5 次重连失败退出本地运行状态，明确提示未确认主机已停止 |

## E 组：多引擎与权限

| # | 操作 | 期望 |

## UI 状态回归（改了事件映射或组件时）

`transport: "replay"` + `?devtools=1`，逐个切换内置场景：思考、工具调用与结果、审批、错误、重试、耗尽/终止、中断、产物。与改动前对比，不能有状态消失。已知缺陷：结构化表单产物显示 `[object Object]`（T2.3）；shell 工具完成后标题仍是「正在运行命令」（上游文案缺完成态）。
