# 03 路线图与进度

**最快路径**：不换底座，不加后端。保留 AgentCanvas 导出的 UI + Pi 运行时，只补“能用起来”缺的四件事：服务端凭据、会话落盘、工作区分离、部署脚本。前面的调研（OpenAgentCore、openbot、OpenXX）只作为行为参考，不引入代码（见 [07](07-decisions.md)）。

工期按 AI 开发、人只做审批和验收估算；“天”指一个有效工作会话日。
