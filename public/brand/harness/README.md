# Harness marks

Original publisher artwork used by the shared 3D Harness tiles and the transparent full-lens artwork on the optional oversized sunglasses. The experimental avatar back flags were removed at the user’s request.
All resources are served locally; no runtime request goes to a publisher.

| File | Publisher source | Treatment |
| --- | --- | --- |
| `pi.svg` | [Pi official logo](https://pi.dev/logo-auto.svg) | Original three paths and colours; viewBox trimmed to the artwork bounds. |
| `claude-code.svg` | [Claude official Clawd](https://claude.ai/images/clawd.svg) | Unchanged original SVG; no invented claws or Claude model asterisk. |
| `codex.png` | Official Codex desktop app 26.1027.61615, `Contents/Resources/icon-codex-light.png` | Original 1024px PNG copied without conversion; the terminal-in-cloud product mark, not the OpenAI company knot. |
| `codex-lens.svg` | Same official Codex PNG above | Transparent preview derivative selected by the user: embedded source PNG with a native SVG blue colour-key/closing filter removes the neutral app tile, preserves the cloud/terminal, and crops the viewBox to the cloud. |
| `dsh-lens.svg` | Same official whale SVG below | Original silhouette in ivory for dark lenses; trimmed vertical viewBox, no background. |
| `dsh.svg` | [DeepSeek Harness public assets](https://github.com/deepseek-ai/deepseek-harness/tree/687f282e8625c6b8d11ff58211a90524be2e4317/apps/web/public) | Original black whale SVG, unchanged. |

Retrieved 2026-11-03. Brand/trademark rights remain with the respective owners. DSH's repository is MIT licensed. Existing Lobe Icons attribution for earlier inline marks remains in [the historical import record](../../../docs/harness-icons.md).

Standalone Harness tiles keep the original assets and colours, including black DSH on ivory. Sunglasses use transparent artwork filling only the right lens, clipped inside the glass with its reflections retained. Pi/Claude use the original SVGs; Codex/DSH use the explicitly documented lens derivatives above.
